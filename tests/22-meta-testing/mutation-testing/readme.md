# Mutation testing 


*   neither a functional nor a non-functional test of a software applications

*   meta-test technique used to evaluate the quality and effectiveness of a test suite.

## Understanding Mutation Testing

*   What it does

    It deliberately introduces small changes (mutations or bugs like changing + to - or > to <) into your source code.

*   How it works

    *   It runs your existing unit tests against this modified code. If your tests fail (meaning they "kill" the mutant),
        your test suite is working well. If your tests still pass, it exposes a gap or weakness in your test cases.

*   The goal

    It tests your tests, not the software's features or behavior.

*   Functional vs. Non-Functional Context

    *   Functional testing checks what the system does against functional requirements (e.g., inputs, outputs, business
        logic).

    *   Non-functional testing checks how the system performs regarding qualities like speed, security, reliability,
        or usability.

    *   Mutation testing falls outside this classic binary because it operates as a structural code-analysis and
        quality-assurance metric for developers' test cases, usually built on top of unit testing.
